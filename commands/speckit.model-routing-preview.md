# Auswahlvorschau / Selection preview

DE: Expliziten Harness, lokale Konfiguration und Phasenanforderungen verlangen.
`scripts/resolve-model-routing.sh -Action Preview` auf macOS/Linux bzw. die
PowerShell-Variante auf Windows verwenden. Das Skript aus diesem Preset
verwenden, solange eine zentrale Kopie noch nicht separat geliefert wurde.
Keine Klassifikation durch einen LLM-Aufruf, kein Refresh, kein Modellstart,
keine Installation. Status, Begruendung, effektive Anforderungen und naechste
sichere Aktion berichten. `Aligned` belegt Auswahl, nicht Modellzugang.

EN: Require an explicit harness, local config and phase requirements. Use this
preset's resolver with `-Action Preview`; an old central copy may not yet
support it. No inference, refresh, model launch or installation. Report status,
reason, effective requirements and next safe action. Aligned proves selection,
not access, quality superiority or execution authority.
